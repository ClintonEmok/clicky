# Requirements: Language Learning for Expats

**Defined:** 2026-04-13
**Core Value:** Help expats keep using their computer in the target language without getting stuck.

## v1 Requirements

### Reading

- [ ] **READ-01**: User can look up selected or visible text and get a concise translation
- [ ] **READ-02**: User can see a short explanation for ambiguous or idiomatic text
- [ ] **READ-03**: User can save unknown words or phrases with source context

### Writing

- [ ] **WRITE-01**: User can get help drafting or rewriting text in the target language
- [ ] **WRITE-02**: User can ask for tone or grammar suggestions for a message or form

### Immersion

- [ ] **IMMR-01**: User can keep the interface mostly in the target language with minimal English fallback
- [ ] **IMMR-02**: User can reduce interruptions and keep help inline instead of modal

## v2 Requirements

### Practice

- **PRACT-01**: User can practice speaking and listening with voice interactions
- **PRACT-02**: User can receive pronunciation feedback

## Out of Scope

| Feature | Reason |
|---------|--------|
| Full lesson curriculum | The product is centered on real computer use, not structured courses |
| Heavy gamification | Competes with immersion and task flow |
| Auto-translate everything | Breaks the target-language environment |
| Mobile app | v1 is desktop-first |
